# QQQ·TLT·GLD·XLE 코어 포트폴리오 — 최종 확정안

**최종 확정일**: 2026-09-16
**대상**: 연금 계좌(세금 없음 가정), 3년 내 은퇴 예정, MDD 감내 한도 -15%
**운용 방식**: 신호 계산 → 텔레그램 알림 → 수동 매매 (반자동)

---

## 1. 핵심 요약

| 자산 | 판정 시점 | 밴드(매수/매도) | 비중조절 방식 | 코어 내 최대비중 |
|---|---|---|---|---|
| QQQ | 매주 금요일 종가 | +0.5% / -1.0% | C (증감형) | 60% |
| TLT | 매주 금요일 종가 | +3.5% / 0% | C (증감형) | 40% |
| GLD | 매달 마지막 금요일 종가 | +1.0% / -1.0% | C (증감형) | 35% |
| XLE | 매달 마지막 금요일 종가 | +4.25% / -2.75% | A (0/50/75/100%) | 20% |

- **체결 방식**: 판정일 종가로 신호 계산 → 익일(월요일) 시가 체결
- **코어 예산**: 100% (4개 자산 목표비중 합이 100%를 넘으면 비례 축소/정규화)
- **거래비용**: 0.05%/회 (백테스트 반영)
- **유휴 현금**: 연 3% 수익 가정 (실제로는 파킹형 상품 등으로 운용 전제)
- **세금**: 연금계좌 가정으로 미반영

## 2. 최종 성과 (2005-12 ~ 현재, 현금 3% 반영)

| 구간 | CAGR | MDD | Sharpe | Calmar |
|---|---|---|---|---|
| ~2015 | 10.9% | -12.2% | 1.12 | 0.89 |
| 2016~2021 | 14.2% | -9.0% | 1.41 | 1.59 |
| 2022 | -8.2% | -12.0% | -0.56 | -0.68 |
| 2023~현재 | 16.7% | -7.9% | 1.61 | 2.13 |
| **전체** | **11.8%** | **-12.2%** | **1.17** | **0.97** |

MDD -12.2%는 사용자 감내 한도(-15%) 이내로, 3~9%p의 완충 여유를 둔 수준이다.

## 3. 방법론 요약

### 3.1 개별 자산 신호
- 20일/120일/200일 이동평균선 각각에 대해 **매수밴드(진입)·매도밴드(이탈)를 독립적으로 갖는 히스테리시스** 방식 사용. 밴드 안에서는 직전 상태를 유지해 휩쏘를 방지.
- 신호개수(0~3개, ON인 이동평균선 수)를 비중조절 방식(A/B/C)에 매핑해 0~100% 목표비중 산출.
  - **방식 A**: 0/50/75/100% (0개 신호 시 완전 청산)
  - **방식 B**: 0/33/66/100%
  - **방식 C**: 신호개수 증감에 따라 ±50%p씩 변화 (경로의존형)
- QQQ·TLT·GLD는 방식C가, XLE는 방식A가 전 구간에 걸쳐 가장 우수했음.

### 3.2 판정 주기
- QQQ·TLT: **주봉**(일봉보다 노이즈에 강함 — 닷컴버블 등 장기 하락장에서 재진입 횟수가 절반 이하로 줄어듦)
- GLD·XLE: **월봉**(가격 추세가 더 완만해 더 긴 호흡의 판정이 유리)
- 단, GLD·XLE 모두 "그 달의 **마지막 거래일**"이 아니라 "그 달의 **마지막 금요일**" 기준으로 통일 — QQQ·TLT와 같은 요일(금요일 판정 → 월요일 실행) 리듬을 맞추기 위한 운영상의 결정.

### 3.3 코어 통합
- 각 자산의 목표비중 = 자산 자체 신호값(0~1) × 자산별 최대비중(캡)
- 4개 자산 목표비중의 합이 코어 예산(100%)을 넘으면 **비례 축소(정규화)**
- 캡(60/40/35/20)은 QQQ 비중을 먼저 사용자가 -15% MDD 기준으로 정한 뒤, 나머지 3자산의 캡을 그리드서치(5%p 간격, 균형점수 = CAGR/MDD/Sharpe/Calmar 정규화 평균)로 탐색해 확정.

## 4. 거친 검증

- **밴드 민감도 테스트**: 개별 자산 밴드 및 최종 코어 캡 모두, 선택된 값 주변이 완만한 "고원" 형태인지(안정적) 확인. QQQ 월봉 후보 등 일부는 이 테스트에서 탈락시켜 폐기함.
- **워크포워드 검증**: 학습구간(~2015)만 보고 새로 찾은 배분과, 전체기간 기준으로 찾은 확정안을 검증구간(2016~현재)에서 비교. **확정안이 검증구간에서 오히려 성과가 개선**된 반면, 순수 학습구간 최적해(대개 XLE를 배제)는 검증구간에서 크게 악화 — 확정안의 강건성 확인.
- 밴드·비중 모두 이 과정을 반복 적용했으며, 상세 로그는 대화 기록 참고.

## 5. 자동화

- `core_signals.py`: 매일 실행되는 무상태(stateless) 신호 계산 스크립트. yfinance로 전체 히스토리를 매번 다시 받아 재계산하므로 별도 상태 저장이 불필요.
- `.github/workflows/daily_signal.yml`: 매일 KST 06:30(월~토) 실행, 텔레그램 발송.
- `.github/workflows/keepalive.yml`: GitHub의 "60일 무활동 시 스케줄 워크플로 자동 비활성화" 정책을 피하기 위해 매주 더미 커밋 1회 생성.
- 메시지 형식: **토·월요일**은 리밸런싱 상세(변경 항목, 정규화 여부, 자산별 MA 상태·이격도), **화~금요일**은 보유 현황 요약만 발송.

## 6. 아직 남은 항목 (알려진 한계)

- **위성(satellite) 슬리브 미구현**: 애초 구상은 "코어에서 남는 현금 중 최대 20%를 위성에 활용"이었으나, XLE가 코어로 편입되면서 위성 설계는 보류 상태.
- **실제 체결 괴리(iNAV) 미검증**: 국내 상장 해외ETF의 실제 체결가와 백테스트 가정(미국장 익일 시가) 사이 오차는 반영되지 않음.
- **완전 자동매매 미구현**: 현재는 신호 통보까지만 자동화되어 있고, 실제 매매는 수동.
- **현금 수익률은 근사치**: 실제 단기금리 데이터를 정밀하게 연동하지 못하고, 연도별 알려진 수준으로 근사함.
- yfinance 데이터와 백테스트에 쓴 원본 CSV 데이터 간 미세한 배당조정 차이 가능성 — 실운영 초기 신호값 육안 검증 권장.
