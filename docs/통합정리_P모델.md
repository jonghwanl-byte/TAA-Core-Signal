## 3. P모델 확정 규칙 (배포 코드 기준, 변경 없음)
| 자산 | 판정 | 이평선 | 밴드 (매수/매도) | 방식 | Cap |
|---|---|---|---|---|---|
| QQQ | 주봉(금요일 종가) | 20/50/100주 | +1.0% / -1.0% | C | 60% |
| TLT | 일봉(매일) | 20/120/200일 | +4.0% / -0.5% | C | 40% |
| GLD | 주봉 | 20/50/100주 | +3.0% / -2.0% | C | 20% |
| XLE | 주봉 | 20/50/100주 | +3.0% / -2.0% | A | 20% |

- 이평선별로 매수/매도 밴드를 둔 히스테리시스(매수: 종가 > MA×(1+매수밴드), 매도: 종가 < MA×(1-매도밴드), 사이는 유지)
- 방식 A: 켜진 신호 3/2/1/0개 → 100/75/50/0%
- 방식 C(기존): 신호 개수가 늘면 +50%p, 줄면 -50%p (하루에 2개 바뀌어도 ±50%p까지만), 0~100%
- 목표비중 = 신호비중 × Cap. 합이 100%를 넘으면 비례 축소, 나머지는 현금
- 주봉은 금요일 종가로 확정되고, 확정된 주봉 신호는 다음 금요일까지 유지
- 데이터: yfinance `auto_adjust=True`(배당 조정가). 백테스트 CSV도 조정가라 기준이 같음

## 5. 검증 결과 요약
### 5-1. P의 낙관 편향 (핵심)
- P의 밴드·Cap은 1단계(자산별 후보 12개)는 ~2015 학습만 썼지만, **2단계(최종 조합·Cap)는 전체 기간(2005~2026) Calmar로 골랐습니다.** 따라서 2019년 이후 성과(15.4% / -11.9%)는 깨끗한 OOS가 아닙니다.
- P의 절차(이평선 20/120/200일·20/50/100주 고정, 자산별 판정주기·밴드·방식·Cap 선택)를 **학습 구간에서만** 다시 돌린 Nested 결과:

| 학습 → 검증 | CAGR / MDD / Sharpe / Calmar | 참고: 기존 P 같은 구간 |
|---|---|---|
| ~2018 → 2019~ | 11.8% / -12.8% / 1.11 / 0.92 | 15.4% / -11.9% |
| ~2015 → 2016~ | 10.1% / -14.2% / 0.99 / 0.71 | 13.0% / -11.9% |

→ 기존 P는 약 3%p 낙관적. 현실적 기대치는 CAGR 10~12%, MDD -13~-14%.
- **위기 하나씩 빼고 학습(그 위기 OOS 수익률 / MDD):** 2008 -7.4% / **-20.8%**, 2020 +18.6% / -12.7%, 2022 -1.5% / -9.5%. 2008 같은 위기를 학습에서 못 본 경우가 최대 위험.
- 정정 이력: 이 채팅 초반에 "P 구조 재선택 시 8.3% / -16.9%"라고 한 것은 **일봉 이평선을 20/50/100으로 잘못 놓은 실수**였고, 위 표가 바른 값입니다.

### 5-3. 방식 C 수정 (변경 신호 개수 × 50%p) 검토
- 기존 P에 수정 C만 적용: 전체 10.9% / -13.7% (기존 11.4% / -11.9%), **체결 1일 지연 MDD -16.4%** (기존 -13.2%). 2019~는 동일(15.4% / -11.8%).
- 결론: 성과 개선이 없고 체결 지연에 더 민감 → **미적용 권고**. 적용하려면 코드 `C_JUMP = True` (백테스트와 일치 확인).
